================================================================================
    reproduce_5 四项目环境配置（Linux + micromamba）
================================================================================

  前提：base 环境已有 PyTorch 1.8 + CUDA 11.1 + Python 3.8
  核心规则：
    1. PyTorch 用 pip（带 CUDA，快）
    2. pytorch3d 用 conda --no-deps（pip 缺旧版本，--no-deps 防 conda 拉 CPU 版 torch 覆盖 pip 版）

├──────────┼──────────┼──────────┼───────────┼───────────┼──────────┤

│ SI-Adv   │ 3D对抗   │ CVPR 22  │ 3.7       │ 1.6(cu101)│ 0.6.0   │
│ HiT-ADV  │ 3D对抗   │ CVPR 24  │ 3.8       │ 1.11      │ 最新     │

================================================================================
  二、GeoA3 — 几何感知 3D 对抗点云
================================================================================

# 不能 clone base：pytorch3d 会拉 conda 版 torch 覆盖 pip 版，导致 CUDA=False

================================================================================
  踩坑备忘
================================================================================

1. pytorch3d 旧版本（0.6.0/0.7.2）pip 没有，必须走 conda-forge/pytorch3d 频道
2. torch 1.6.0 没有 cu102 构建，用 cu101（CUDA 驱动向下兼容）
3. conda 安装 pytorch3d 会连带拉 conda 版 torch（CPU 版），必须 --no-deps 阻止
4. --no-deps 后需手动补装 pytorch3d 的真依赖：fvcore + iopath
5. GeoA3/HiT-ADV 不能 clone base——pytorch3d 会覆盖 pip 版 torch 导致 CUDA=False
6. mayavi 编译需 numpy 先装，HiT-ADV 实际不依赖，直接跳过
7. SI-Adv yml 锁死 100+ 系统库精确版本，解析极慢，手动装核心依赖即可
